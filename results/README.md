# Experiment results

`cifar_resnet_w40/` contains the completed training configuration, per-epoch metrics,
validation split IDs, per-class validation accuracy, and plots. These small
artifacts are included in the code repository so the reported results can be
inspected. The `best.pt` and `last.pt` checkpoints remain local and are ignored
by Git. Run `train.py` to recreate them from the permitted competition data.
